💾 Backup & Restore
Bundles every draft, saved team, roster build, and your theme into a single JSON file. Restore on any device — iPad, Mac, future iPhone — by importing the same file. PWA-vs-Safari storage isolation goes away as soon as the file is in iCloud Drive.
iCloud Drive workflow: first time, open the Files app and create a folder called PokePicker Backups inside iCloud Drive. On Export, iOS opens the Share Sheet — tap Save to Files → iCloud Drive → PokePicker Backups. On Restore, the file picker opens the Files app and you navigate to the same folder.
PokéAPI ability cache is skipped (rebuildable). Restore overwrites local entries with the same keys; it doesn't merge.
